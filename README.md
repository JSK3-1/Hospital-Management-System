Hospital Management System

A Python-based Hospital Management System that allows administrators to manage doctors and patients, assign doctors to patients, record symptoms, update administrator details, and manage patient discharges.

Features

* Administrator login
* Register, view, update and delete doctors
* View patient information
* Assign doctors to patients
* Record patient symptoms
* Discharge patients
* View discharged patients
* Update administrator details

Technologies Used

* Python
* Object-Oriented Programming (OOP)

Project Structure

* main.py — Runs the main hospital management system
* Admin.py — Handles administrator operations
* Doctor.py — Handles doctor information and patient assignments
* Patient.py — Handles patient information and symptoms

How to Run

1. Make sure Python is installed.
2. Download or clone the repository.
3. Run main.py.
4. Log in using the administrator credentials provided in the program.

Purpose

This project was created to practise Python programming, object-oriented programming, data management, and working with multiple classes and modules.
